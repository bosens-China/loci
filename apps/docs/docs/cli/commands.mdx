# CLI 命令参考

运行 `loci --help` 查看当前版本的完整帮助。命令缺少必填参数时会在交互终端中提示输入；在 CI 或管道中，请通过选项提供全部必填值。

删除、覆盖导入和清空数据会要求确认。仅在自动化脚本中确认目标正确时使用 `--yes` 跳过确认。

## 基础命令

| 命令             | 说明                                                |
| ---------------- | --------------------------------------------------- |
| `loci status`    | 显示本地知识库、同步任务、云端副本和 MCP 摘要。     |
| `loci update`    | 检查 CLI 是否有新版本。                             |
| `loci doctor`    | 检查数据库、浏览器、Server 和 MCP，并给出修复建议。 |
| `loci --version` | 显示 CLI 版本。                                     |
| `loci --help`    | 显示命令帮助。                                      |

## 本地文档源

| 命令                          | 说明                               |
| ----------------------------- | ---------------------------------- |
| `loci source list`            | 列出本地文档源。                   |
| `loci source add`             | 添加公开文档源。                   |
| `loci source update [source]` | 修改文档源，不改变桌面端定时计划。 |
| `loci source delete [source]` | 删除文档源及其全部文档。           |
| `loci source sync [source]`   | 在前台同步文档源。                 |
| `loci source runs [source]`   | 查看抓取记录。                     |

`source add` 与 `source update` 支持以下选项：

| 选项                             | 说明                          |
| -------------------------------- | ----------------------------- |
| `--name <name>`                  | 文档源名称。                  |
| `--url <url>`                    | 第一个公开文档页面 URL。      |
| `--mode <auto\|http\|browser>`   | 抓取方式。`auto` 会自动判断。 |
| `--page-limit <number>`          | 页面上限。                    |
| `--scope <path>`                 | 收录路径。                    |
| `--http-concurrency <number>`    | HTTP 并发覆盖值。             |
| `--browser-concurrency <number>` | 浏览器并发覆盖值。            |

`source delete` 支持 `--yes` 跳过删除确认。

## 浏览和搜索文档

| 命令                            | 说明                           |
| ------------------------------- | ------------------------------ |
| `loci document list [source]`   | 列出文档。                     |
| `loci document tree [source]`   | 按 URL 路径显示文档目录。      |
| `loci document search [query]`  | 搜索标题和 Markdown 正文。     |
| `loci document read [document]` | 输出一篇 Markdown 文档的全文。 |

文档列表和搜索结果会显示文档短 ID，可用作后续命令中的 `[document]` 参数。`source list` 会显示文档源短 ID。

## 云端公开文档库

先使用 `loci config set server-url <url>` 设置 Loci Server 地址。

| 命令                          | 说明                              |
| ----------------------------- | --------------------------------- |
| `loci cloud list`             | 列出云端公开文档库及本地状态。    |
| `loci cloud pull [library]`   | 下载云端文档库到本地。            |
| `loci cloud update [library]` | 从原 Server 更新本地云端副本。    |
| `loci cloud remove [library]` | 删除本地云端副本，不影响 Server。 |

`cloud remove` 支持 `--yes` 跳过删除确认。

## MCP

| 命令                          | 说明                                |
| ----------------------------- | ----------------------------------- |
| `loci mcp stdio`              | 通过 stdio 提供 Loci MCP。          |
| `loci mcp serve`              | 以前台方式启动 HTTP MCP 服务。      |
| `loci mcp status`             | 显示 MCP 地址、端口和当前宿主。     |
| `loci mcp configure [client]` | 将 Loci MCP 写入 Agent 客户端配置。 |

`mcp configure` 的 `[client]` 可为 `codex`、`cursor`、`vscode`、`claude-code` 或 `gemini-cli`。它支持 `--transport <stdio\|http>`；默认值为 `stdio`。

## 浏览器

| 命令                     | 说明                                              |
| ------------------------ | ------------------------------------------------- |
| `loci browser status`    | 检查 Chromium headless shell 是否已安装且可启动。 |
| `loci browser install`   | 安装版本匹配的 Chromium headless shell。          |
| `loci browser uninstall` | 删除 CLI 管理的浏览器。                           |

`browser uninstall` 支持 `--yes` 跳过删除确认。

## 共享设置

CLI 与桌面应用共用设置和本地数据。使用以下命令查看或修改设置：

```bash
loci config list
loci config set <key> <value>
```

| 设置项                | 说明                 |
| --------------------- | -------------------- |
| `mcp-port`            | MCP HTTP 端口。      |
| `http-concurrency`    | HTTP 抓取默认并发。  |
| `browser-concurrency` | 浏览器抓取默认并发。 |
| `server-url`          | Loci Server 地址。   |

## 数据管理

| 命令                        | 说明                                   |
| --------------------------- | -------------------------------------- |
| `loci data export [file]`   | 导出与桌面应用兼容的 JSON 备份。       |
| `loci data import [file]`   | 用备份覆盖当前本地数据。               |
| `loci data clear-documents` | 清空文档和全文索引，保留文档源。       |
| `loci data clear-sources`   | 清空文档源、文档、全文索引和抓取历史。 |

`data import`、`data clear-documents` 和 `data clear-sources` 支持 `--yes` 跳过确认。

## Server 管理

`loci admin` 进入 Loci Server 管理员交互会话。它会要求输入管理员账号和密码，可在会话中查看、创建、修改、删除或同步 Server 文档库。

管理员登录信息仅保存在当前进程内存中。退出会话后，CLI 会清除登录信息。

## 临时数据目录与退出码

设置 `LOCI_DATA_DIR` 可使用独立数据目录，适合测试或隔离环境。日常使用不建议设置该变量，因为 CLI 与桌面应用默认共享同一份本地数据。

| 退出码 | 含义                                 |
| ------ | ------------------------------------ |
| `0`    | 成功或用户主动取消。                 |
| `1`    | 认证、网络、运行时或内部错误。       |
| `2`    | 参数或用户输入错误。                 |
| `3`    | 操作完成，但存在页面失败或诊断异常。 |
