# CLI 安装与快速上手

安装 Node.js 22.16 或更高版本，然后安装 Loci CLI。

```bash
npm install --global @boses/cli
loci --version
loci --help
```

## 从一页文档开始

先查看本机已有的库。第一次使用时，可用以下示例把 Rspress 的入门页收录为 `rspress`。`--pages` 仅抓取给定页面，`--wait` 会等待抓取结束，方便随后读取。

```bash
loci list --json
loci fetch https://rspress.rs/guide/introduction.html --pages --name rspress --wait
loci tree rspress --json
loci search Rspress --library rspress --json
loci read /guide/introduction.html --library rspress --json
```

若站点发生重定向，使用 `tree` 返回的实际文档 ID 或路径读取。`search` 返回匹配的段落和小节，`read` 返回正文及原文 URL。之后运行 `loci update rspress --pages https://rspress.rs/guide/introduction.html` 可精确刷新该页，`loci status rspress --json` 查看最近进度与结果。整库发现与范围控制见 [页面发现与抓取](/cli/crawling)。

## 打开 Web UI

```bash
loci ui
```

默认地址为 `http://127.0.0.1:4520`。终端会打印地址并尝试打开浏览器。知识管理、Agent 接入、无头浏览器、设置与数据共用本机运行时；按 `Ctrl+C` 关闭会话并停止其正在执行的抓取。要只打印地址并由系统选择端口，使用 `loci ui --port 0 --no-open`。

浏览、编辑和删除命令见 [本地文档库](/cli/commands/local-library)。脚本输出、浏览器和配置见 [基础命令与运行设置](/cli/commands/basics)。让 Agent 使用同一份资料见 [接入 Agent](/agent/overview)。
