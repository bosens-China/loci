# CLI 安装与使用

Loci CLI 适合终端、自动化脚本和服务器环境。它将公开技术文档保存为本地 Markdown，供后续搜索、阅读和 Agent 查询。

## 安装 CLI

CLI 需要 Node.js 22.13 或更高版本。

示例：

```bash
npm install --global @boses/cli
loci --help
```

如果要抓取依赖浏览器渲染的文档站，再安装 Chromium headless shell。普通 HTTP 文档站不需要这一步。

示例：

```bash
loci browser install
```

## 收录第一份文档

以下示例使用最短命令收录 Rspress 文档。只提供 URL 时，名称从域名生成，抓取方式为 `auto`，页面上限为 1,000，收录范围为整个站点。

示例：

```bash
loci source add https://rspress.rs/guide/introduction.html
loci source sync rspress
```

接口文档同样只需提供正在阅读的地址。输入 Swagger UI、Knife4j、ReDoc、FastAPI `/docs` 或常见 OpenAPI JSON 地址时，Loci 会自动发现同站的 OpenAPI/Swagger JSON，并直接整理接口、参数、响应、认证和数据模型；没有发现规范时继续按普通网页收录。

示例：

```bash
loci source add http://localhost:8000/docs
```

公开 GitHub 仓库也可以直接作为文档源。Loci 会收录默认分支中的 Markdown；不需要安装 Git 或浏览器。

示例：

```bash
loci source add https://github.com/vuejs/docs
```

同步完成后，使用关键词查找文档。命令会显示每篇文档的短 ID；可用短 ID 读取全文。

示例：

```bash
loci document search "Quick start"
loci document read <短 ID>
```

可以随时查看本地数据和文档源：

示例：

```bash
loci status
loci source list
```

打开浏览器控制台时，Loci 会先打印访问地址、尝试打开浏览器，并在当前终端保持前台服务；按 `Ctrl+C` 会结束本次会话：

```bash
loci ui
```

需要让定时更新脱离 UI 终端持续运行时设置计划即可，保存时会确保用户级后台服务可用：

```bash
loci schedule set rspress '0 2 * * *'
```

云端每日同步同样会自动准备后台服务。在 Web UI 中开启定时抓取或每日同步时，当前会话先负责执行；按 `Ctrl+C` 正常结束后自动交接给后台服务，无需再补一条启动命令。
