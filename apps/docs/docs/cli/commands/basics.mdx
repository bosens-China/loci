# 基础命令与运行设置

## 终端与 Web UI

| 命令 | 用途 |
| --- | --- |
| `loci --help` | 列出命令。用 `loci read --help` 等子命令帮助查看参数。 |
| `loci --version` | 打印当前 CLI 版本。 |
| `loci upgrade --json` | 检查 npm 上的 CLI 版本。省略 `--json` 时，有更新会显示升级命令。 |
| `loci ui --port 0 --no-open` | 在本机回环地址启动 Web UI，自动选端口并打印地址。默认端口为 4520。 |
| `loci cancel <library> --json` | 取消指定库正在运行的抓取。 |
| `loci status [library] --json` | 查询指定库或各库的最近抓取记录。 |

库参数支持完整 ID、唯一 ID 前缀或唯一的名称。供脚本使用的 `--json` 放在相应子命令之后；默认异步抓取的退出码 `0` 表示已启动或复用，轮询 `status` 获取最终结果。加 `--wait` 时进度写入 stderr。前台抓取全部成功时退出码为 `0`，有失败时为 `1`，抓取被信号取消时为 `130`。命令行参数解析错误为 `2`。

## 浏览器

```bash
loci browser status --json
loci browser install --json
loci browser uninstall
```

依赖客户端渲染的网页可使用与当前 Playwright 版本匹配的 Chromium headless shell。`status` 会检查安装路径和启动能力，无法启动时返回退出码 `3`。卸载会要求确认，非交互执行可在确认目标后传 `--yes`。

## 共享设置

```bash
loci config list --json
loci config set theme dark
loci config set github-archive-limit-mb 250
loci config domain set docs.example.org --http-concurrency 2
loci config domain set docs.example.org --http-concurrency inherit
loci config domain list --json
loci config domain remove docs.example.org
```

`loci config` 和 `loci config list` 均显示当前设置。`loci config set <key> <value>` 接受主题 `theme`（`auto`、`light`、`dark`），以及 `http-concurrency`、`browser-concurrency`、`max-retries`、`batch-interval-seconds`、`batch-interval-max-seconds`、`github-archive-limit-mb` 和 `github-markdown-limit-mb`。

`loci config domain set <hostname>` 支持 `--http-concurrency`、`--browser-concurrency`、`--batch-interval-min-seconds` 和 `--batch-interval-max-seconds`。每项可填整数或 `inherit`，后者清除该项覆盖。

移除域名策略需要确认。已核对目标的非交互脚本可用 `loci config domain remove <hostname> --yes`。

`LOCI_DATA_DIR` 可为当前进程选择数据目录，`LOCI_CACHE_DIR` 可选择缓存目录（含受管浏览器与更新检查缓存）。交互式终端执行 CLI 命令（含直接运行 `loci`）或打开 Web UI 时会在后台非阻塞检查新版本。共享缓存的 CLI 和 Web 会复用同一次在途检查，Web 顶栏会在检查完成后刷新。可设置 `LOCI_NO_UPDATE_CHECK=1`、`NO_UPDATE_NOTIFIER=1` 或 `CI=true` 关闭自动检查。希望 CLI 与 Web UI 共享数据和浏览器时，对相关命令使用相同的目录。备份操作见 [数据备份与恢复](/cli/commands/data)。
