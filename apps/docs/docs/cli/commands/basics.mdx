# 基础、浏览器与设置

本页介绍通用命令和浏览器运行时。需要调整抓取资源或编写自动化脚本时，请查看[高级配置与自动化](/cli/advanced)。

## 参数约定

命令用法中的 `<参数>` 为必填参数，`[参数]` 为可选参数。例如，`loci source sync [source]` 可以指定文档源，也可以省略后在终端中选择。

`[source]` 可以使用文档源名称、完整 ID 或唯一的短 ID。`[document]` 还可以使用文档标题或文档 URL。涉及删除、导入或清空数据的命令会要求确认；仅在自动化脚本中确认目标无误后，才使用 `--yes` 跳过确认。

## 基础命令

### `loci --help`

显示 CLI 的总帮助和可用命令分类。要查看某个子命令的参数，可在命令后追加 `--help`。

示例：

```bash
loci source add --help
```

### `loci --version`

显示当前安装的 CLI 版本。`-V` 是它的简写。

示例：

```bash
loci --version
```

### `loci status`

汇总本地文档源、云端副本、已收录文档、最近同步记录、MCP 状态和 Loci Server 地址。

示例：

```bash
loci status
```

### `loci update`

立即检查 npm 上是否存在更新的 Loci CLI 稳定版本，并显示当前版本和最新版本。

示例：

```bash
loci update
```

### `loci doctor`

检查 Loci 运行环境，并在发现问题时给出修复建议。

示例：

```bash
loci doctor
```

## 无头浏览器

当文档站需要 JavaScript 渲染时，CLI 会在 `auto` 检测或 `browser` 抓取前检查 Chromium headless shell。交互终端中可以确认并自动安装；非交互环境需要提前运行安装命令。

### `loci browser status`

检查无头浏览器是否已安装且可以启动。

示例：

```bash
loci browser status
```

### `loci browser install`

安装与当前 CLI 版本匹配的 Chromium headless shell。

示例：

```bash
loci browser install
```

### `loci browser uninstall`

删除由 CLI 管理的无头浏览器。默认会要求确认；`--yes` 可跳过确认。

示例：

```bash
loci browser uninstall
```

## 查看设置

设置保存在 Loci 本地数据目录中。CLI、stdio MCP 和 HTTP MCP 都会读取这些设置。

### `loci config list`

显示当前设置，包括云端文档库地址和抓取资源限制。

示例：

```bash
loci config list
```

### `loci config set [key] [value]`

修改一个设置。省略参数时，CLI 会在交互终端中选择设置项并要求输入新值。

```bash
loci config set server-url https://your-loci.example.com
```

云端文档库地址请查看[云端文档库](/cli/commands/cloud-library)。抓取并发、重试、下载上限和 HTTP MCP 端口请查看[高级配置与自动化](/cli/advanced)。
