# 本地文档库

本页介绍如何创建、同步和浏览本机文档库。`source` 命令管理公开网站或仓库，`document` 命令用于浏览已保存的 Markdown。

## 创建文档源

### `loci source add [url]`

将任意公开文档页作为入口。首次使用或当前数据目录没有已保存的创建偏好时，只提供 URL 会自动生成名称，以 `auto` 模式、1,000 页上限和整站范围开始，并立即执行首次同步。交互终端之后会复用最近的抓取方式、页面上限和收录路径层级；显式选项始终优先，非交互调用不读取这些偏好。

```bash
loci source add https://rspress.rs/guide/introduction.html
```

常用选项如下：

| 参数                             | 用途                                        |
| -------------------------------- | ------------------------------------------- |
| `--url <url>`                    | 覆盖位置参数中的入口 URL。                  |
| `--name <name>`                  | 指定文档源名称。                            |
| `--scope <path>`                 | 只收录指定路径，例如 `/guide`。             |
| `--page-limit <number>`          | 限制最多收录的页面数。                      |
| `--mode <auto\|http\|browser>`   | 选择自动、HTTP 或浏览器抓取。               |
| `--exclude-path <regex>`         | 排除匹配的 URL 路径，例如不需要的语言目录。 |
| `--http-concurrency <number>`    | 覆盖这个普通站点的 HTTP 并发数。            |
| `--browser-concurrency <number>` | 覆盖这个普通站点的浏览器并发数。            |
| `--archive-limit <size>`         | 覆盖这个 GitHub 仓库的 ZIP 上限。           |
| `--markdown-limit <size>`        | 覆盖这个 GitHub 仓库的 Markdown 总量上限。  |
| `--no-sync`                      | 只保存文档源，稍后再同步。                  |
| `--background`                   | 提交持久后台任务，使当前终端立即返回。      |

`--background` 与 `--no-sync` 不能同时使用。CLI 会在执行前直接拒绝这组冲突参数。

例如，只收录指南并排除中文、德文和法文目录：

```bash
loci source add https://fastapi.tiangolo.com/ --scope /tutorial --exclude-path '^/(zh|de|fr)(?:/|$)'
```

需要调整并发数、重试次数或 GitHub 大小上限时，请查看[基础命令与运行设置](/cli/commands/basics)。

### GitHub 仓库

公开 `github.com/<owner>/<repo>` 仓库可以直接作为文档源：

```bash
loci source add https://github.com/vuejs/docs
```

Loci 会保留仓库 Markdown 的目录结构，并保持相对文档和图片链接可用。当前只支持公开仓库的默认分支；不支持私有仓库、Git LFS、Git clone、子目录范围和 MDX。

## 同步和更新文档源

### `loci source sync [source]`

同步一个本地文档源，并显示成功和失败的页面数：

```bash
loci source sync rspress
```

`auto` 模式发现页面需要 JavaScript 渲染时，会提示安装浏览器运行时。脚本环境请先执行：

```bash
loci browser install
```

前台同步也会先写入持久任务队列再等待结果。重复同步同一文档源时，Loci 会复用正在运行的任务；即使后台服务或另一个 MCP 入口先认领，CLI 也会读取同一份进度与最终结果。失败或取消后，可以再次执行同步。

### `loci task`

抓取任务具有稳定 ID，并持久保存每个页面的完成事件。可以在另一个终端查看、跟随或取消：

```bash
loci task list
loci task status <任务 ID>
loci task follow <任务 ID>
loci task follow <任务 ID> --format jsonl
loci task cancel <任务 ID>
```

`task follow` 会从持久事件按序读取逐页进度，轮询较慢或重新运行命令不会影响后台抓取。跟随时按 `Ctrl+C` 只退出当前显示并保留任务；`task cancel` 才会取消 pending 或 running 任务，重复取消会返回相同终态。

### `loci source list`

列出本地文档源，包括页面数、内容大小、页面获取方式和收录范围：

```bash
loci source list
```

### `loci source update [source]`

修改文档源名称、入口 URL、页面获取方式、页面上限或收录范围。完全省略修改选项时，CLI 会进入编辑向导：

```bash
loci source update rspress --page-limit 300
```

`update` 同样支持 `--http-concurrency`、`--browser-concurrency`、`--archive-limit` 和 `--markdown-limit`。省略覆盖值时会保留当前来源设置；创建时省略则继承共享设置。

切换来源类型、把 URL 切换到其他 hostname，或把 GitHub 来源切换到另一仓库，会立即清空现有正文。收窄范围或新增、修改排除规则会在保存事务中立即删除不再匹配的正文和搜索索引，不会等到下次同步。交互向导会在保存前再次警告；显式传入更新选项表示脚本已经确认对应影响。保存后建议立即同步。

### `loci source runs [source]` 与 `loci source logs [run]`

使用 `source runs` 查看最近的同步记录；使用 `source logs` 排查某次同步的页面失败原因：

```bash
loci source runs rspress
loci source logs a1b2c3d4
```

`source logs` 中的 `[run]` 是 `source runs` 输出的短 ID。如需查看所有文档源的记录，使用 `--all`：

```bash
loci source runs --all
```

交互终端可以省略文档源并从列表中选择。非交互终端必须指定文档源，或显式传入 `--all` 查看全部记录。

## 设置定时更新

### `loci schedule set [source] [cron]`

为本地文档源设置五段 Linux Cron 更新计划。传入 `off` 可以关闭计划：

```bash
loci schedule set rspress '0 2 * * *'
loci schedule set rspress off
loci schedule list
```

使用默认数据目录时，保存启用的计划会立即确保无 HTTP 的用户级常驻 worker 可用。Web 会话与 worker 可以同时运行，之后无需保持终端或浏览器打开；机器恢复或服务重新启用后，错过的多个时间点最多合并补跑一次。设置 `LOCI_DATA_DIR` 时只会为该目录启动当前登录会话中的独立 detached worker，不会安装对应的登录或重启自启动定义；需要长期运行时应由容器或进程管理器执行同一环境下的 `loci service run`。旧脚本中的 `manual` 仍可作为 `off` 的兼容别名。

服务状态和停用方式请查看[后台服务与 Web UI](/cli/commands/service)。计划列表为空时，CLI 会提示先创建文档源或使用 `schedule set` 配置计划。

## 删除文档源

### `loci source delete [source]`

删除一个本地文档源及其全部文档。CLI 默认会再次确认：

```bash
loci source delete rspress
```

## 浏览和读取文档

### `loci document list [source]`

列出已保存的文档：

```bash
loci document list rspress
```

### `loci document tree [source]`

按 URL 路径显示文档库目录：

```bash
loci document tree rspress
```

### `loci document search [query]`

在文档标题和正文中搜索关键词：

```bash
loci document search "部署配置"
```

### `loci document read [document]`

读取一篇文档的 Markdown 内容和来源 URL。`[document]` 可以是短 ID、标题或完整 URL：

```bash
loci document read a1b2c3d4
```

需要使用 Server 上预先发布的公开文档时，请查看[云端文档库](/cli/commands/cloud-library)。
