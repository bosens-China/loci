# Admin：部署与管理 Server

:::tip 可选阅读

本页面向需要在服务器上部署 Loci Server 的管理员。只在本机维护个人文档库时，可以跳过本页。

:::

部署 Loci Server 后，你可以集中抓取公开文档，并将只读快照提供给团队成员或其他用户。

Loci Server 不接收用户的本地文档。它只抓取无需登录即可访问的公开 HTTP/HTTPS 文档，并发布管理员选定的文档库。

## 部署 Loci Server

仓库根目录提供了生产环境使用的 `compose.yaml` 和环境变量示例。服务器需要安装 Git、Docker 和 Docker Compose。

克隆仓库后，复制环境变量示例：

```bash
cp .env.example .env
```

至少需要在 `.env` 中设置以下值：

| 环境变量              | 用途                                            |
| --------------------- | ----------------------------------------------- |
| `LOCI_ADMIN_PASSWORD` | Admin 登录密码，应替换为足够长的随机值。        |
| `LOCI_ADMIN_USERNAME` | Admin 登录账号，默认是 `admin`。                |
| `LOCI_BROWSER_TOKEN`  | Loci Server 连接 Browserless 时使用的随机令牌。 |
| `LOCI_SERVER_PORT`    | 发布到宿主机的端口，默认是 `3000`。             |

保存配置后启动服务：

```bash
docker compose up --build -d
```

确认健康检查可以访问：

```bash
curl http://127.0.0.1:3000/health
```

生产环境应通过 HTTPS 反向代理暴露 Loci Server，并保留 Compose 创建的 `loci-data` 数据卷。当前版本按单实例运行，不要让多个 Server 实例同时写入同一份 SQLite 数据。

## 连接部署后的 Server

在管理员使用的电脑上安装 Loci CLI，然后将默认 Server 地址改为部署后的 HTTPS 地址：

```bash
loci config set server-url https://loci.example.com
loci doctor
```

`loci doctor` 会检查 `/health` 是否可以访问。其他用户也需要设置同一个地址，之后便可通过 `loci cloud list` 浏览已发布的文档库。

## 使用 Admin 会话

运行以下命令进入交互式管理会话：

```bash
loci admin
```

CLI 会读取管理员账号和隐藏输入的密码。登录后可以执行以下操作：

- 查看 Server 文档库；
- 创建文档库；
- 修改文档库入口和抓取计划；
- 删除文档库及其已发布快照；
- 手动同步并查看同步进度。

创建或修改文档库时，需要填写名称、第一个公开文档页面 URL、页面上限和抓取计划。抓取计划使用五段 Linux Cron，例如 `0 2 * * *` 表示每天 02:00 运行；留空表示关闭定时同步。

管理员密码和登录 Token 只保存在当前 CLI 进程的内存中。退出 Admin 会话后，CLI 会注销 Token，下一次管理时需要重新登录。

## 发布后的用户流程

Server 完成首次同步后，其他用户可以下载只读快照：

```bash
loci config set server-url https://loci.example.com
loci cloud list
loci cloud pull <文档库名称或 ID>
```

下载后的内容保存在用户本地，可以离线浏览，也可以由本机 Loci MCP 读取。用户不能通过公开文档库接口修改 Server 上的文档源。

## 部署边界

- 只添加公开且无需登录的文档页面，不要填写 Cookie、Token 或其他站点凭据。
- Hash Router 文档站依赖 `#` 区分页面，当前不适合作为文档源。
- 生产机还应通过防火墙或云网络策略阻止容器访问内网和云元数据地址。
- Browserless 只在 Compose 内部网络提供浏览器能力，不应直接暴露到公网。

如果只需要使用别人已经发布的文档库，请返回[云端文档库](/cli/commands/cloud-library)，无需阅读或执行本页的部署步骤。
