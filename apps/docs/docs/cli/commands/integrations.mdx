# 数据备份与清理

本页介绍 CLI 的本地数据维护命令。导入或清理前建议先执行导出备份。

## 数据备份与清理

### `loci data export [file]`

导出本地文档库的 JSON 备份。省略文件路径时，会在当前目录生成带 UTC 毫秒时间的文件，例如 `loci-backup-2026-08-04T01-02-03-456Z.json`，并拒绝覆盖同名文件。显式传入 `[file]` 表示由用户指定目标；如果该文件已存在，CLI 会直接覆盖，不再二次确认。

示例：

```bash
loci data export
```

### `loci data import [file]`

从 JSON 备份恢复数据，并覆盖当前本地数据。默认会展示备份摘要后要求确认；`--yes` 可跳过确认。

示例：

```bash
loci data import ./backups/loci-2026-08-04.json
```

省略文件参数时会打开带补全的路径选择器，并只接受实际存在的文件。读取成功后仍会先展示备份中的文档源和文档数量，再确认覆盖本地数据。

### `loci data clear-documents`

清空全部文档，但保留文档源配置。之后可以通过 `loci source sync <source>` 重新收录内容。`--yes` 可跳过确认。

示例：

```bash
loci data clear-documents
```

### `loci data clear-sources`

清空全部文档源、文档和抓取历史。`--yes` 可跳过确认。

示例：

```bash
loci data clear-sources
```

需要在脚本中隔离数据目录，或根据退出码处理任务结果时，请查看[高级配置与自动化](/cli/advanced)。
