# 数据备份与运行环境

本页介绍 CLI 的本地数据维护命令和运行环境。数据与桌面应用共享，导入或清理前建议先执行导出备份。

## 数据备份与清理

### `loci data export [file]`

导出一个与桌面应用兼容的 JSON 备份。省略文件路径时，会在当前目录生成带 UTC 毫秒时间的文件，例如 `loci-backup-2026-08-04T01-02-03-456Z.json`，并拒绝覆盖同名文件。显式传入 `[file]` 表示由用户指定目标；如果该文件已存在，CLI 会直接覆盖，不再二次确认。

示例：

```bash
loci data export
```

### `loci data import [file]`

从 JSON 备份恢复数据，并覆盖当前本地数据。默认会展示备份摘要后要求确认；`--yes` 可跳过确认。

示例：

```bash
loci data import ./backups/loci-2026-08-04.json
```

省略文件参数时会打开带补全的路径选择器，并只接受实际存在的文件。读取成功后仍会先展示备份中的文档源和文档数量，再确认覆盖本地数据。

### `loci data clear-documents`

清空全部文档和全文索引，但保留文档源配置。之后可以通过 `loci source sync <source>` 重新收录内容。`--yes` 可跳过确认。

示例：

```bash
loci data clear-documents
```

### `loci data clear-sources`

清空全部文档源、文档、全文索引和抓取历史。`--yes` 可跳过确认。

示例：

```bash
loci data clear-sources
```

## 运行环境

### 临时数据目录

设置 `LOCI_DATA_DIR` 可以让 CLI 使用独立数据目录，适合测试或隔离环境。日常使用不建议设置该变量，因为默认数据目录与桌面应用共用。

示例：

```bash
LOCI_DATA_DIR=./.loci-test loci status
```

### 退出码

| 退出码 | 含义                                 |
| ------ | ------------------------------------ |
| `0`    | 成功或用户主动取消。                 |
| `1`    | 认证、网络、运行时或内部错误。       |
| `2`    | 参数或用户输入错误。                 |
| `3`    | 操作完成，但存在页面失败或诊断异常。 |
