# 桌面应用快速上手

Loci 桌面应用用于管理和搜索本地文档。它将公开文档保存为本地 Markdown，不会上传文档内容。

## 下载与安装

前往 [GitHub Releases](https://github.com/bosens-China/loci/releases) 下载对应平台的安装包。

- Windows：下载并运行 `.exe` 安装包。
- macOS：下载 DMG，拖动 Loci 到“应用程序”。未签名版本首次打开时，可能需要在“隐私与安全性”中选择“仍要打开”。
- Linux：下载 AppImage，赋予执行权限后运行。

安装后，Windows 与 Linux 版本会每天在后台检查正式更新，发现新版后自动下载，并在退出 Loci 时安装。也可以在“系统设置 → 关于 Loci”手动检查。macOS 版本仍会提示新版，但需要从 GitHub Releases 手动下载并安装 DMG。

## 收录第一份文档

启动应用后，打开“文档源”页面并选择“添加文档源”。填写公开文档的首页 URL，保留推荐抓取方式，然后执行同步。

同步完成后，打开“文档库”页面即可浏览和搜索已收录的文档。桌面应用和 CLI 共享本地数据，可以在任一入口查看相同的文档、抓取记录和同步结果。

重复点击同一文档源的同步按钮不会启动第二份抓取。后发请求会复用正在运行的任务和最新进度。桌面应用与 CLI 同时运行时，跨进程锁会阻止它们同时写入同一文档源。
