# 桌面应用快速上手

Loci 桌面应用用于管理和搜索本地文档。它将公开文档保存为本地 Markdown，不会上传文档内容。

## 下载与安装

前往 [GitHub Releases](https://github.com/bosens-China/loci/releases) 下载对应平台的安装包。

- Windows：下载并运行 `.exe` 安装包。
- macOS：下载 DMG，拖动 Loci 到“应用程序”。未签名版本首次打开时，可能需要在“隐私与安全性”中选择“仍要打开”。
- Linux：下载 AppImage，赋予执行权限后运行。

## 收录第一份文档

启动应用后，打开“文档源”页面并选择“添加文档源”。填写公开文档的首页 URL，保留推荐抓取方式，然后执行同步。

同步完成后，打开“文档库”页面即可浏览和搜索已收录的文档。桌面应用运行期间会自动提供本机 HTTP MCP；如果同时安装 CLI，建议优先使用 CLI 的 stdio 接入方式。

重复点击同一文档源的同步按钮不会启动第二份抓取。后发请求会复用正在运行的任务和最新进度。桌面应用、CLI 和本机 MCP 共享数据目录时，还会通过跨进程锁阻止多个进程同时写入同一文档源。
