# 使用 use-loci Skill

`use-loci` 随 CLI 分发。Agent 可以按任务加载它，也可以在提问时指定“使用 use-loci，查找本项目依赖版本的路由配置并引用原文”。查询与抓取步骤见 [接入 Agent](/agent/overview)。

## 为当前项目安装

在项目根目录执行以下命令。默认客户端为 `universal`，默认项目为当前工作目录。安装和更新使用同一个 `add` 命令。

```bash
loci skills add use-loci
loci skills list --json
```

用 `--project <path>` 指定项目，用 `--global` 选择用户级目录，两者互斥。可选 `--agent` 值为 `universal`、`codex`、`cursor`、`claude-code`、`vscode`、`antigravity` 和 `all`。`all` 会合并相同的物理目标目录。

```bash
loci skills add --agent cursor --project ./ --yes
loci skills list --agent cursor --project ./ --json
loci skills add --agent codex --global --yes
```

## 移除与清理

`remove` 接受可选名称，默认 `use-loci`。`clear` 清理所选范围内受管的安装。写操作会提示确认，非交互调用需要 `--yes`。

```bash
loci skills remove use-loci --agent cursor --project ./
loci skills clear --agent all --global
```

Loci 用本地安装记录与目录中的 `.loci-skill.json` 核对所有权。手工删除、编辑或与已有目录冲突时，先查看 `list` 的 `status` 和 `targetPath`。需要同时同步全局 Skill 和 Rules 时使用 `loci setup <client>`。规则的目标位置见 [配置全局规则](/agent/global-rules)。
