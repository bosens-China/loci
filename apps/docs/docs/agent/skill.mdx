# 使用 use-loci Skill

`use-loci` 随 CLI 分发。Agent 可以按任务加载它，也可以在提问时指定“使用 use-loci，查找本项目依赖版本的路由配置并引用原文”。查询与抓取步骤见 [接入 Agent](/agent/overview)。

CLI 参数和示例由本站维护。Agent 可以按需读取 [Markdown 文档索引](https://bosens-china.github.io/loci/llms.txt)，离线时用 `loci <命令> --help`。

## 为当前项目安装

在项目根目录执行以下命令。默认客户端为 `universal`，默认项目为当前工作目录。安装和更新使用同一个 `add` 命令。

```bash
loci skills add use-loci
loci skills list --json
```

用 `--project <path>` 指定项目，用 `--global` 选择用户级目录，两者互斥。可选 `--agent` 值为 `universal`、`codex`、`cursor`、`claude-code`、`vscode`、`antigravity`、`pi` 和 `all`。`all` 会合并相同的目标目录。

```bash
loci skills add --agent cursor --project ./ --yes
loci skills list --agent cursor --project ./ --json
loci skills add --agent codex --global --yes
```

Pi 的项目级 Skill 安装到 `.pi/skills/`，Pi 信任该项目后才会加载。全局 Skill 安装到 Pi 配置目录的 `skills/`，默认是 `~/.pi/agent/skills/`。Pi 也能读取 `universal` 的 `.agents/skills/`。卸载 Pi 专用安装会保留通用 Skill。 [Pi 技能文档](https://docs.pi.dev/latest/skills#add-it-to-pi)

## 移除与清理

`remove` 接受可选名称，默认 `use-loci`。`clear` 清理所选范围内受管的安装。写操作会提示确认，非交互调用需要 `--yes`。

```bash
loci skills remove use-loci --agent cursor --project ./
loci skills clear --agent all --global
```

Loci 用本地安装记录与目录中的 `.loci-skill.json` 核对所有权。`loci setup <client>` 可备份占用目标的旧 Skill 并同步全局 Rules。全局接入升级见 [接入 Agent](/agent/overview#升级旧接入)。

Skill 安装、更新或移除中途被中断时，下次检查或操作该目标会先恢复未完成的事务，再继续执行。
