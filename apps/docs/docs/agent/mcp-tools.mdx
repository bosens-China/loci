# 工具使用参考

本页面向编写 Agent、Skill 或自动化流程的用户。只需在客户端中配置 Loci MCP 时，请先阅读[通过 MCP 接入](/agent/mcp)。

## 不建立 MCP 连接时直接调用

`use-loci` Skill 在当前会话没有 Loci MCP 工具时，可以在用户同意安装 CLI 后调用同一批工具：

```bash
loci mcp call loci_list_libraries
loci mcp call loci_search_files --input '{"queries":["router"]}'
```

该方式不写入客户端配置，也不启动 MCP 服务。已有 MCP 工具时，应直接调用工具，避免重复执行。

## 工具分组

| 分组 | 用途                                                   |
| ---- | ------------------------------------------------------ |
| 发现 | 列出本地文档库和云端公开库。                           |
| 定位 | 查看目录树，或按关键词搜索正文。                       |
| 阅读 | 读取 Markdown 文件或搜索命中的完整小节。               |
| 管理 | 添加、拉取、同步、查询状态、查看失败详情和删除文档库。 |

列出、查看、搜索和读取属于只读操作。拉取、新增抓取、同步和删除会访问网络或修改本地状态，Agent 必须先得到用户当前请求或明确确认。

## 创建与搜索

`loci_add_library` 默认使用自动抓取、1,000 页上限和站点根路径。Agent 了解目标路径或任务规模时，可以覆盖抓取方式、页面上限和收录范围。

`loci_search_files` 会先尝试精确匹配；没有结果时再放宽搜索条件。搜索 API 名、配置键和错误原文时，优先使用原始文本。

同一域名、同一路径的网页库会复用已有文档库；同一站点的不同路径可以独立收录。

## 等待同步结果

添加或同步文档库后，可以直接检查状态；需要等待完成时，传入 `wait_for_completion: true`。同一文档库已在同步时，后续调用会复用已有任务和进度。

同步响应会给出失败数量和样例。需要逐页排查时，再使用 `loci_list_sync_failures` 分页读取详情。

详细输入字段以当前 MCP 工具 Schema 为准。CLI 的 `loci mcp call <tool> --input '<json>'` 与 MCP 使用相同的工具名和输入字段。
